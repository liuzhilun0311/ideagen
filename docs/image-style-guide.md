# 图片风格与创作流程

## 推荐与最终选择

新生成的大纲会返回一个推荐风格、推荐理由和两个备选。推荐信息独立于页面文字保存，不进入发布文案。模型未返回有效推荐时使用主题规则推荐。

“自动推荐”在生成前解析为具体风格。同一作品使用同一推荐；用户已经手动选择时，重新生成大纲不会覆盖该选择。旧作品没有推荐元数据时，自动模式以扁平信息图作为保守回退；也可以直接手动选择。

整套默认风格与本页试用风格独立。推荐只影响自动模式；图片请求以本次最终选择为准。主体身份、事实、数字与上图文字不随画风变化。风格补充用于细化颜色和细节，不能反向覆盖预设媒介。

风格库按稳定的预设 ID 对应样图，不再借用其他风格的样图。标注“模型实测 · 2K”的图片通过应用实际提示词组装与模型调用生成，使用统一的“桌面绿植照料”主题，便于比较媒介、材质和构图。放大预览显示完整原图，缩略图单独压缩以加快加载。

本批样图使用 `gpt-image-2.5-flare`、低质量档、3:4、1536 × 2048 像素，于 2026-09-27 生成。2K 是像素尺寸，不等于高质量档。样图只证明该模型在本次题材下的表现，不保证其他主题、模型或宽高比会有相同结果。摄影、聊天和纪实类样图均是合成展示，不是真实人物、客户反馈或业务证据。

手动改过内置提示词时显示“原始预设样图 · 提示词已修改”，不会把旧图宣称为改后提示词的实测结果。自定义参考图片优先展示；缺少独立图片或审核未通过时明确提示，不拿相近画风冒充。建议先试一页，确认文字和图形关系后再批量生成。

## 推荐操作

1. 生成大纲并检查每页文字，查看推荐风格。
2. 在正文页选择本页试用风格，点击“生成本页 · 1 张”。
3. 切换候选缩略图，满意后选择“采用此版本”。
4. 选择“将此风格用于整套”，再生成剩余图片。
5. “当前采用”下查看原图、处理图或对比；候选生成版本不与后处理版本混用。

手机端通过底部设置入口打开设置抽屉，开始单页生成后返回预览。图片加载失败时选择“重新加载图片”，不用重复生成。

系统提示词备份位于 `data/prompt-backups/2026-09-10-style-library/`。本次未修改用户自定义提示词和已有作品。

## 内容层次与发布文案

系统默认提示词会先为每页选择适合内容的表达结构，例如清单、步骤、对比、分类或关系图。图片中的“上图文字”只包含读者需要看到的标题、短标签和要点；“画面描述”只用于安排视觉主体和阅读顺序，不会作为图片文字或发布事实。

生成图片时，最终选择的图片风格决定插图、线条、材质和色彩倾向；页面结构决定信息如何组织。手绘、漫画、信息图等风格不会改变页面中的事实、数字、步骤或结论。

发布平台和获客目标作为提示词的适配约束参与生成，不是替换事实来源，也不是图片中的可见标签。图片和发布文案共享同一组事实；发布文案可以补充语境，但仍需检查没有新增不实承诺。平台选择不等于自动发布，生成后仍应核对正文、行动引导和图片内容。

本次系统默认提示词备份位于 `data/prompt-backups/2026-09-11-xiaohongshu-content-hierarchy/`。用户自己创建、复制或共享的提示词不会被自动修改，已有作品也不会被重写。
