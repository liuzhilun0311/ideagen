11. 旧重绘路径补传用户参考图和维度；有作品记录时单页及失败重试使用已采用首图，不猜测旧的 0.png。
12. 文本模型客户端延迟初始化，明确选择的有效模型不再被默认服务商配置失败阻断。
13. 诊断明确区分配置/提示词检查与结果验证；没有宣称图片文字或语义已被识别验证。

## 使用及兼容边界

- 刷新本地页面后使用新版。已有生成结果不会自动重写；新的生成、预览、保存使用新逻辑。
- 历史作品以前没有存储的素材不能凭空恢复。旧记录仍可打开；重新附加素材并保存后才有完整新快照。
- 新快照每个作品最多5张参考图，每张不超过5MB，原始素材只提供给有修改权限的用户。
- 质量“旧版默认”保留此前低档默认值的兼容含义；不支持质量档位的接口实际使用自身默认值。格式在保存阶段保证，非所有服务商都原生返回所选编码。
- 分辨率与平台规则已传入支持的接口，但上游仍可能拒绝或不遵守。诊断记录实际输出尺寸，不能据请求值承诺实际尺寸。
- 多平台选项仍表示一份通用图文，不代表自动生成多个平台的独立版本。抖音按图文处理，不擅自改写为视频脚本。
- 字数是软目标；没有新增“严格字数”产品选项。未为凑字数自动重试并增加费用。
- Responses 保持原最小兼容请求，不盲目加入模型可能不支持的采样参数。实际发送字段以脱敏上游日志为准。
- 未进行付费模型调用。受众适配、风格美感、图中文字正确性和事实真实性，仍需使用真实样例评测及人工检查；当前诊断不会把这些标记为已验证。
