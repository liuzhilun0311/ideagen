# IdeaGen 专业生产力工作台 UI/UX 优化设计

## 1. 目标

在不改变现有生成、保存、预览、历史记录和模型配置业务行为的前提下，优化 IdeaGen 的整体布局、视觉层级和高频操作路径，使其更适合连续创作和批量处理。

核心目标：

- 让用户始终清楚当前所在模块、当前作品和当前页面。
- 让“生成、保存、预览”成为明确的主流程。
- 降低工作台中设置项和次要操作对编辑区域的干扰。
- 让桌面端保持较高信息密度，移动端保持可用且不产生横向滚动。
- 统一首页、作品、提示词、模型设置等页面的基础视觉语言。

## 2. 设计原则

- **任务优先**：围绕当前创作任务组织信息，而不是围绕组件类型堆叠内容。
- **主次分明**：每个区域只保留一个主要动作，次要动作采用次级按钮、图标按钮或折叠设置。
- **上下文就近**：当前页面的编辑、预览和页面级操作放在中间工作区附近；整套作品操作放在顶部。
- **稳定布局**：加载、生成和错误状态不导致主要区域跳动。
- **生产力密度**：桌面端使用紧凑但不拥挤的间距，正文保持可读字号。
- **可访问交互**：保留键盘焦点、语义标签、状态播报和至少 44px 的触摸目标。

## 3. 全局布局

### 3.1 顶部应用导航

保留现有固定顶部导航和模块路由：

- 创作
- 作品
- 提示词
- 模型
- 用户管理（管理员）

调整方向：

- 品牌区域保持稳定宽度。
- 导航项使用统一图标、文字和选中状态。
- 当前模块使用浅色背景和主色文字，不使用过重阴影。
- 用户信息与退出操作归入右侧账户区。
- 移动端继续使用抽屉式导航，并保证打开后焦点和 Escape 关闭行为可用。

### 3.2 页面容器

- 桌面端使用统一最大内容宽度和左右内边距。
- 页面标题区统一为：标题、辅助说明、页面级操作。
- 内容区与标题区之间保持固定垂直节奏。
- 表格、图库和工作台在自身容器内处理溢出，不撑宽页面。

## 4. 首页创作入口

首页的首要任务是输入主题并开始生成大纲。

布局：

1. 页面标题区：`新建创作` 与一句简短说明。
2. 主创作区：主题输入、参考内容、图片素材和开始生成。
3. 辅助设置区：大纲选项、模型选择、提示词检查。
4. 状态反馈区：加载、错误、不可用模型、已有任务等状态靠近主创作区展示。
5. 灵感区：作为低优先级入口，保持可扫描的卡片网格。

交互：

- 主题为空时，开始按钮保持禁用或提交后就近提示。
- 生成过程中锁定会改变当前任务的设置，但保留取消入口。
- 已有草稿时，开始新创作继续使用确认提示。
- 模型不可用时，错误信息提供直接进入模型设置的入口。
- 灵感卡片点击只替换主题，不隐式清除参考内容和设置。

## 5. 工作台布局

### 5.1 桌面端三栏结构

工作台继续作为核心页面，使用三栏生产布局：

- **左栏：页面结构**
  - 页面缩略图或序号
  - 当前选中状态
  - 页面排序、删除、新增
  - 页面生成状态
- **中栏：当前页面**
  - 当前页面标题和内容编辑
  - 图片预览或空状态
  - 页面级预览、重试、后处理和候选图采用
- **右栏：上下文工具**
  - 页面风格试验
  - 图片生成参数
  - 页面级提示词检查
  - 后处理设置

三栏应使用稳定的最小宽度和 `minmax(0, 1fr)`，中栏始终获得最大剩余空间。右栏低频设置可折叠，避免挤压编辑器。

### 5.2 顶部工作台操作区

顶部按优先级排列：

1. 返回与作品标题
2. 保存状态
3. 新建、导出等图标操作
4. 保存
5. 预览作品

“预览作品”作为唯一最高优先级的页面级 CTA；保存使用次级按钮；导出、新建使用图标按钮并提供 tooltip。

### 5.3 生成工具区

将生成工具区分成两层：

- **整套作品操作**：生成剩余页面、重新生成全部页面、停止后续生成。
- **当前页面操作**：当前页面重试、样式试验、候选图预览和采用。

低频模型、尺寸和后处理选项不与主要生成按钮争夺同一视觉层级。生成中的按钮显示明确状态并禁用重复提交。

### 5.4 发布文案模式

发布文案与图片制作共享工作台标题和顶部操作区，但内容区使用更宽的编辑区域：

- 左侧不显示页面列表。
- 中间为标题、正文、标签三个清晰分区。
- 右侧保留文案生成和复制相关辅助操作。
- “生成文案”是唯一主操作。
- 支持复制全部文案，并在按钮附近播报成功或失败结果。

## 6. 响应式策略

### 375px

- 顶部导航收进菜单。
- 工作台使用底部三段式切换：结构、编辑、工具。
- 生成参数和后处理改为全宽纵向布局。
- 所有按钮和输入控件保持至少 44px 高度。
- 禁止页面级横向滚动。

### 768px

- 保留紧凑的桌面式工作台，但降低左右栏宽度。
- 页面标题和操作区允许换行。
- 表格、图库和工具栏在自身容器内换行或滚动。

### 1024px

- 使用完整三栏工作台。
- 右栏保持足够的控件可读宽度。
- 顶部保存状态可按空间隐藏文字，仅保留状态图标和 tooltip。

### 1440px

- 内容区使用统一最大宽度。
- 中间编辑器扩大，左右栏保持稳定宽度。
- 避免把大面积留白误用成装饰，优先用于编辑内容和预览。

## 7. 视觉系统

- 延续浅色生产力工具方向：浅灰背景、白色工作区、蓝色主操作。
- 正文颜色保持高对比度，弱化文字不低于可读对比要求。
- 卡片圆角保持不超过 8px，减少装饰性阴影。
- 统一按钮、输入框、标签和分页的高度、圆角和焦点样式。
- 使用 `lucide-vue-next` 图标，不使用 emoji 作为界面图标。
- 交互反馈采用 150–300ms 的颜色、边框和透明度过渡，不使用导致布局跳动的缩放。

## 8. 状态与错误反馈

- 生成、保存、后处理等异步任务都要有稳定的加载状态。
- 错误信息显示在相关任务区域附近，并提供可执行的恢复操作。
- 成功提示使用短文本和 `role="status"`。
- 作品不可用时保留本地草稿，并突出“转为新作品继续”。
- 页面状态不能只依赖颜色，同时使用文字、图标或状态标签。

## 9. 实现边界

本次优化优先修改：

- `frontend/src/App.vue`
- `frontend/src/views/HomeView.vue`
- `frontend/src/views/WorkspaceView.vue`
- `frontend/src/assets/css/variables.css`
- `frontend/src/assets/css/base.css`
- `frontend/src/assets/css/components.css`
- 工作台和页面级组件中与布局、按钮层级直接相关的局部样式

不在本次范围内：

- 后端 API、数据模型和生成协议变更
- 无关业务逻辑重构
- 重新设计品牌 Logo 或生成新的插画资源
- 改变既有路由和核心数据流

## 10. 验收标准

- 首页、作品、提示词、模型设置和用户管理页面拥有一致的标题区与内容间距。
- 工作台桌面端能清晰区分页面结构、当前编辑区和上下文工具。
- 每个主要场景只有一个明确主按钮。
- 生成、保存、错误和恢复状态在视觉上稳定且语义清楚。
- 在 375px、768px、1024px、1440px 下无页面级横向滚动。
- 键盘可访问导航、按钮、输入框、抽屉和对话框。
- 现有前端类型检查、单元测试和构建命令通过。
