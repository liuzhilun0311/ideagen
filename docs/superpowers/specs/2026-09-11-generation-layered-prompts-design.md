# 分层生成提示词与图片参数设计

**日期：** 2026-09-11  
**状态：** 已确认，待实施

## 目标

将 IdeaGen 的生成链路明确拆分为四层：

1. 大纲组织方式：决定整套内容如何展开。
2. 单页布局：决定当前页面如何排版。
3. 图片风格：决定画面如何表现。
4. 图片参数：决定最终输出规格。

各层职责独立，避免提示词重复、参数冲突和诊断信息不完整。

## 设计范围

本次只调整以下范围：

- 大纲提示词及大纲结构化输出。
- 图片提示词及单页布局、最终风格的传递。
- 图片生成请求的分辨率、宽高比、质量和输出格式。
- 单页生成、批量生成、重试生成的参数一致性。
- 本地摘要和上游请求诊断中的实际参数记录。

不改动作品管理、下载、去 AI 化、用户共享等已完成功能。

## 分层职责

### 大纲层

大纲生成提示词负责：

- 理解主题、受众和内容目标。
- 使用用户选择的整套内容组织方式。
- 确定页面数量和页面顺序。
- 为每一页生成标题、正文要点和内容重点。
- 为每一页推荐单页布局。
- 根据主题和内容推荐图片风格。

大纲输出需要保留以下结构化信息：

```json
{
  "organization": "分类递进",
  "style_recommendation": {
    "preset": "handwritten-notes",
    "reason": "适合把复杂知识拆成易扫描的笔记结构"
  },
  "pages": [
    {
      "type": "cover",
      "layout": "分类总览",
      "title": "页面标题",
      "content": ["页面要点"],
      "visual_focus": "页面视觉主体"
    }
  ]
}
```

旧数据缺少新字段时，系统使用兼容默认值，不阻塞历史作品打开。

### 图片层

图片提示词只负责当前页面的内容表达：

- 当前页必须渲染的文字内容。
- 当前页的单页布局。
- 当前页的视觉主体或构图重点。
- 用户最终选择的图片风格。
- 文字准确性、安全边距和禁止无关文字等通用约束。

图片提示词不得具体写入以下参数值：

- `1K`、`2K`、`4K`
- `1:1`、`3:4` 等宽高比
- `low`、`medium`、`high` 等质量值
- `PNG`、`JPEG`、`WebP`

提示词只保留原则性说明：

```text
图片分辨率、宽高比、质量和输出格式以接口参数为准，不在提示词中自行改变或覆盖。
```

大纲组织方式不重复注入图片提示词；图片请求只使用当前页面所需内容，避免发送整套无关页面文本造成额外成本。

### 风格层

风格由独立风格目录提供，最终选择优先于推荐值：

1. 用户对当前页的最终选择。
2. 用户设置的整套默认风格。
3. 大纲推荐风格。
4. 系统默认风格。

风格提示词保持短小，只描述能改变画面效果的关键特征，例如线条、材质、色彩和渲染方式，不重复页面布局和图片参数。

### 参数层

每次图片请求都必须携带完整、有效的结构化参数，即使用户没有手动修改：

```json
{
  "resolution": "1K",
  "aspect_ratio": "3:4",
  "quality": "low",
  "output_format": "png"
}
```

参数优先级：

1. 当前请求中用户明确选择的参数。
2. 已保存的整套默认参数。
3. 系统默认值：`1K`、`3:4`、`low`、`png`。

后端将逻辑分辨率和宽高比转换为上游接口需要的 `size`，并确保 `quality`、`output_format` 和 `n` 同时进入上游请求。`AUTO` 只能作为前端兼容选项，发送前必须转换为有效的实际分辨率，不得直接发送给不支持它的上游。

## 请求诊断

每次图片生成记录：

- 当前页索引。
- 使用的服务商和模型。
- 最终图片提示词。
- 是否使用参考图及参考图数量。
- 本地标准化参数。
- 实际发送给上游的请求体。
- 上游返回的状态、响应头摘要和响应体摘要。
- 请求耗时和尝试 ID。

敏感信息继续按现有规则脱敏，不记录 API Key。

诊断中的参数必须能对应实际请求：

```json
{
  "parameters": {
    "resolution": "1K",
    "aspect_ratio": "3:4",
    "quality": "low",
    "output_format": "png"
  },
  "request_body": {
    "size": "768x1024",
    "quality": "low",
    "output_format": "png",
    "n": 1
  }
}
```

## 错误处理

- 参数缺失时使用系统默认值，不发送空值。
- 参数不受支持时在请求前标准化或返回明确的字段错误。
- 生成失败时保留旧图片和旧候选版本。
- 诊断记录失败请求，便于区分前端参数问题、后端转换问题和上游拒绝。

## 验收标准

1. 大纲输出包含组织方式、每页布局和风格推荐，旧大纲仍可打开。
2. 图片提示词包含当前页内容、单页布局和最终风格。
3. 图片提示词不包含具体图片参数值。
4. 用户最终选择的风格覆盖大纲推荐风格和默认风格。
5. 单页、批量和重试请求都携带相同规则下的完整图片参数。
6. 未选择参数时，请求仍发送 `1K`、`3:4`、`low`、`png` 对应的有效值。
7. `AUTO` 不会直接发送到不支持它的图片上游。
8. 诊断页面能同时看到本地参数摘要和实际上游请求中的参数。
9. 后端相关测试通过，前端生产构建通过。
