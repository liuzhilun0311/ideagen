# IdeaGen 产品升级设计

**日期：** 2026-09-09

## 目标

将现有 IdeaGen 升级为一个从“灵感输入”到“图文成品”的通用 AI 创作工作台，保留现有生成能力，同时改善视觉层级、创作连续性、状态反馈、移动端体验和云端 Docker 部署能力。

## 用户与核心场景

产品面向多种创作者：自媒体、运营人员、营销人员和普通灵感记录者。默认作品类型为社交媒体图文套装，包含封面、多页内容图、标题、正文和标签；架构预留海报、故事卡片、PPT 配图等模板。

## 产品结构

### 首页：灵感入口

首页只突出一个主任务：描述想法并开始创作。

- 顶部导航：品牌、创作、作品、模板、设置。
- 主输入区：主题必填；参考内容和参考图片为可选项。
- 默认自动选择图文套装、模型和基础参数。
- “更多设置”展开模板、画幅比例、视觉风格、模型和高级参数。
- 展示少量模板入口，但不让模板选择阻塞首次创作。
- 输入内容保存在 Pinia 和 localStorage，刷新后可恢复。
- 生成大纲前在输入附近显示校验错误；请求中显示可取消状态。

### 创作工作台：连续编辑

大纲和图文编辑保持同一创作上下文，减少不必要的页面跳转。

- 左侧：作品标题、页面列表、页面类型、排序、插入和删除。
- 中央：当前页面的图像预览、标题、正文和标签编辑区。
- 右侧：生成工具、提示词、模型、进度和错误状态。
- 桌面端使用三栏布局；平板端收窄为双栏；手机端改为上下分区，并通过底部工具栏切换“结构 / 编辑 / 生成”。
- 图片生成和文案生成可独立执行。
- 每张图片显示待生成、生成中、成功、失败和重试状态。
- 生成中禁止破坏性离开，但允许取消；取消后恢复可编辑状态。
- 生成失败时在对应页面就地说明原因和重试操作，不用全屏错误替代上下文。

### 结果页：作品交付

- 以完整作品预览为主，提供页面缩略图导航。
- 支持重新编辑、返回工作台、单图重试、下载和去 AI 化。
- 下载控件明确区分原图、去 AI 化图片和文案文件。
- 下载进行中保留进度和禁用状态，失败时显示可重试反馈。

### 次要模块

历史记录、模型设置、提示词管理和用户管理沿用现有功能，但统一导航、间距、表格、弹窗、空状态、错误态和移动端布局。

## 视觉与交互系统

- 风格：浅色、克制、专业创作工具，不使用营销式大面积装饰。
- 主色：蓝紫用于主要行动和选中状态；中性色用于结构；橙色仅用于退出、警告和危险操作。
- 卡片圆角不超过 8px；页面区块以无框布局为主，卡片仅用于重复项目、弹窗和确实需要边界的工具。
- 统一使用 SVG 图标集，不使用 emoji 作为界面图标。
- 所有按钮和图标按钮具备 hover、active、focus-visible 状态。
- 交互目标最小尺寸 44x44px；正文移动端不小于 16px。
- 动画仅用于状态切换和反馈，时长 150-300ms，并尊重 `prefers-reduced-motion`。
- 图片具备描述性 alt 文本；表单输入具备 label；颜色不是唯一状态指示。
- 验证视口：375px、390px、768px、1024px、1440px，禁止横向滚动和文字遮挡。

## 数据流与后端边界

保留 Django API、Pinia store、SSE 图片生成和现有历史记录模型。前端增加明确的生成任务状态模型，统一处理：

`idle -> validating -> running -> cancelling -> cancelled`

成功状态为 `success`，异常状态为 `error`，每个任务保存错误信息、已完成数量、总数量和可重试项。

接口层需要保证：

- 取消请求与前端 AbortController 都执行。
- SSE 连接断开时展示恢复或重试选项。
- 图片 URL 继续遵守用户隔离和 token 校验。
- 保存草稿与生成结果互不覆盖未提交编辑。
- 后端错误转换为稳定的用户可读错误结构。

## Docker 云部署

生产部署使用 Docker Compose 和单域名入口：

- Nginx：HTTPS、前端静态资源、API/SSE 反向代理和安全响应头。
- Django：使用生产 WSGI/ASGI 进程提供 API 和文件访问。
- SQLite：继续使用现有数据库，挂载持久化 volume。
- `history/` 和 `user_configs/`：挂载持久化目录。
- 配置通过环境变量注入，禁止将 API Key 写入镜像。
- 增加服务健康检查、日志输出、启动说明和备份说明。
- Nginx 对 SSE 禁用缓冲并设置合理的超时。
- 前端使用响应式 Web，不单独实现原生 App；后续可扩展 PWA。

## 错误处理

- 输入错误：显示在对应输入区下方。
- 供应商或模型不可用：在生成工具旁说明并提供设置入口。
- 单页图片失败：只标记该页并允许重试。
- SSE 中断：保留已完成内容，提示继续或重试。
- 下载失败：保留作品状态，提供再次下载。
- 未登录或权限不足：统一跳转/提示，不泄漏资源路径。

## 验证标准

- 前端类型检查和生产构建成功。
- 后端现有测试与新增生成状态测试通过。
- 核心流程可完成：登录、输入主题、生成大纲、编辑、生成图片、生成文案、保存、预览、下载。
- 取消和单图重试均有回归验证。
- 电脑和手机视口无横向滚动、无文字遮挡、主要按钮可操作。
- Docker Compose 配置可构建并启动，容器健康检查通过。
- 生产部署文档能指导用户在云服务器上启动、更新和备份。

## 范围控制

本阶段不重写 AI 服务商协议、不开发原生移动 App、不引入新的计费系统。模板扩展只完成结构预留和默认图文套装的完整体验。
